# Message drafting - Joe's approved style

Read before writing any draft with `write_draft`. One bullet per rule, each with the edit that produced it. Person-specific lessons live in that person's vault note under `## Writing to them`, not here.

- **Shortcut comment to a person: open with their `@<shortcut-handle>` mention alone on the first line, then a blank line, then the body.** No "Thanks <name>," or "Hi <name>," greeting. Evidence: 2026-11-02, Joe hand-edited the sc-56530 reply to Lenar, replacing "Thanks Lenar, reproduced the white screen locally." with "@lenarrakhmatulin".
- **Start the body with the finding, not a thank-you or a "I did X" status line.** In that same edit he removed both the thanks and "reproduced the white screen locally" and kept everything from the cause onward. One edit cannot separate which of the two he disliked, so treat both as unwanted openers until another edit says otherwise.
- **Say where a fix is by environment name, not by what it is not.** 2026-11-02: Joe corrected "not deployed yet" (read as "not in production") to "pushed to develop", since develop is deployed to the dev environment. State the real state: "pushed to develop", "live on prod", never a negation of a different environment.
